> A modern **Hybrid Mobile Application** combining **Blazor Web UI components** with native **.NET MAUI** host capabilities for cross-platform Android, iOS, Windows, and macOS deployment.

---

## 🌟 Architecture & Capabilities

```
┌─────────────────────────────────────────────────────────────┐
│ Blazor Web UI Component Layer (HTML5 / CSS / Razor)        │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ .NET MAUI BlazorWebView Host & Native Device APIs           │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ Native Android / iOS / Windows Operating System Runtime     │
└──────────────────────────────┴──────────────────────────────┘
```

- ⚡ **100% Code Reuse**: Share razor components and C# domain logic between web and mobile applications.
- 📱 **Native Device Access**: Access camera, GPS location, bluetooth, and local file storage directly from Blazor components.
